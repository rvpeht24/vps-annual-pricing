## 下单前必须知道的四条限制

这部分是多数推荐文章不会写的，全部来自官方条款原文。

**第一，14 天退款有红线。** VPS 新购可以 14 个自然日内提工单退款，但以下情况全部不退：已用流量超过 10GB；每个账号终身只能退一次；加密货币和银行转账付款；续费订单；折扣闪购产品（包括上面提到的 BF 促销款）；申请过换 IP；账号之间过户；IP 已被列入黑名单或有关联滥用举报。想保留退款资格，付款用 PayPal 或信用卡，测试期间别把 10GB 流量跑满。

**第二，流量双向计费。** 官网明确「同时计入上行和下行流量」。跑备份、网盘这类单向大流量的业务时要按两倍估算，1TB 标称流量实际大约等于 500GB 上行加 500GB 下行的用量。Storage 系列标称 5TB 起步，就是因为这个口径。

**第三，不支持跨机房迁移。** 想把服务器从法兰克福搬到东京，只能新购一台、迁移数据、再退旧的。下单前想清楚机房，圣何塞比大部分城市贵 €2/月起。

**第四，实名与反欺诈审核。** 下单必须填真实法定姓名和居住地址，订单经反欺诈系统和人工双重审核，挂代理或 VPN 下单、信息对不上会被拒单退款。欧洲账户结账时还可能被额外加收 VAT。
